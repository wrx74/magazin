От тензоров до вкуса: как агенты получают инструменты

Открытая экосистема машинного обучения по-прежнему держится на нескольких крупных фреймворках. PyTorch с более чем 105 тысячами звёзд даёт тензорные вычисления и динамические нейросети на Python с ускорением на GPU, TensorFlow под Apache-2.0 добавляет распределённое обучение и глубокие сети, а Transformers от Hugging Face описывает и запускает модели для текста, зрения, аудио и мультимодальных задач — как для инференса, так и для обучения.

Вокруг них складывается прикладной слой. LangChain предлагает платформу для агентов и RAG, Ollama — локальный запуск Kimi, GLM, DeepSeek, Qwen, Gemma и других моделей, а Open WebUI даёт дружелюбный интерфейс к Ollama и OpenAI API. Firecrawl снабжает агентов веб-данными через единый API к 550+ провайдерам, PaddleOCR превращает PDF и изображения в структурированные данные на 100+ языках, RAGFlow развивает контекстную инфраструктуру, а коллекция awesome-llm-apps собирает более сотни примеров агентов и RAG-приложений.

Инфраструктурная часть также заметна: OpenVINO оптимизирует и развёртывает инференс, Univer предлагает офисный SDK для людей и агентов, open-design — локальное пространство совместного дизайна, а Paperclip помогает управлять агентами в рабочих процессах. Chrome DevTools MCP подключает браузерные инструменты к кодовым агентам, AG-UI описывает протокол взаимодействия агента с фронтендом, а alibaba/open-code-review совмещает детерминированные пайплайны с LLM-агентом для ревью кода.

Отдельная линия — навыки для кодовых агентов. ffmpeg-skill даёт 42 локальных инструмента для работы с видео, ECC оптимизирует обвязку агентов, prompts.chat собирает промпты сообщества, stitch-skills связывает агентов с сервером Stitch MCP, taste-skill учит агентов арт-дирекшну, agent-skills от Addy Osmani предлагает производственные инженерные приёмы, а superpowers оформляет методологию агентной разработки.
